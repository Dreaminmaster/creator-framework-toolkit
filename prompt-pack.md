# Creator Framework Toolkit — 53-Prompt Companion Pack

53 battle-tested content prompts for creators.
Usage: copy a prompt, replace {variables}, paste into any AI chat (or the Toolkit extension).

Quick start:
1. Pick your channel (Twitter / LinkedIn / SEO / Email)
2. Fill in the variables in { }
3. Run 3 variations, keep the best one

## Twitter/X Hooks

1. `Write 5 contrarian hooks about {topic} that challenge common beliefs`

2. `Write a story-hook opening: 'I wasted {time} learning this about {topic}'`

3. `Write a hook with a specific number: '{N} lessons from {topic}'`

4. `Write a 'hot take' hook about {topic} that would spark debate`

5. `Write a hook using the 'you're making this mistake' pattern for {topic}`

6. `Rewrite this boring headline as a viral hook: {headline}`

7. `Write a curiosity-gap hook for {topic} (don't reveal the payoff)`

8. `Write a hook that starts mid-sentence for {topic}`

9. `Write a data-hook: cite a surprising stat about {topic} (invent plausible format)`

10. `Write a 'nobody talks about this' hook for {topic}`

11. `Convert this paragraph into a 3-line Twitter hook: {paragraph}`

12. `Write 5 hooks with different CTAs (repost/follow/like/comment) for {topic}`
