# Creator Framework Toolkit v1.1

A privacy-friendly, offline Chrome extension for drafting social content with reusable writing frameworks.

## Included
- Chrome extension: hook variations, LinkedIn structures, thread outlines, local content checker
- 53-prompt companion pack for use with any AI assistant
- Installation guide

## Honest capability statement
The extension itself does **not** call an AI service. It runs locally and combines your topic with curated writing frameworks. The companion prompts can be copied into an AI assistant of your choice. The Content Check analyzes only pasted text using transparent heuristics; it does not crawl URLs or promise rankings.

## Install
1. Unzip `creator-framework-toolkit-extension-v1.1.0.zip`.
2. Visit `chrome://extensions`.
3. Enable Developer mode.
4. Click **Load unpacked** and select the unzipped extension folder.
