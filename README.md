# Creator Framework Toolkit

This repository contains a local, privacy-friendly writing toolkit for creators, founders, and marketers.

## What it does
- Hook variations using reusable writing frameworks
- LinkedIn post structures with selectable tones
- Seven-part thread outlines
- Local text checks for length, sentence size, headings, links, and repeated words
- 53 prompts for use with any AI assistant
